Does one exit

REFLEX asks a narrow question the existing single-shot calculators do not: when an exit changes the resolution fee, how does that new fee shape the next round of exit decisions?

This is not a prediction, an audit, or an official Standard Reserve product. It is a reproducible sensitivity model built around explicitly labeled assumptions.

05Methodology

Published mechanism.
Explicit behavior model.

REFLEX deliberately separates the protocol shape we can source from the behavioral layer we invented for research.

PUBLISHED SHAPEP = W / (D + W)

Trailing withdrawals over withdrawn + still-held value. The methodology source includes a redacted denominator guard; REFLEX does not invent it.

PUBLISHED SHAPEfee = floor + (ceiling − floor) × q²

REFLEX uses a normalized quadratic interpolation where q = clamp(P / saturation, 0, 1). Floor, ceiling and saturation stay assumptions until launch.

REFLEX MODELscore = b + c·exitₜ₋₁ − d·feeₜPr(exit) = logistic(β·score)

This is not a Standard Reserve formula and does not claim to model real psychology. It only exposes how different sensitivities alter feedback.
